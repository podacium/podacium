## The Problem We Solve

**Fragmented Ecosystem:** Algerian professionals juggle Udemy for learning, Upwork for freelancing, and Power BI for analytics — three silos that don't talk to each other.

**Payment Barriers:** Global platforms don't support DZD, EDAHABIA, or CIB cards. Algerian freelancers lose up to 30% in conversion fees and delays.

**Trust Deficit:** No verified credential system exists for Algerian skills. Employers can't validate qualifications; freelancers can't prove expertise.

**Bias Against Local Talent:** Global freelancing platforms algorithmically disadvantage Algerian providers. Local expertise is undervalued.

## Our Solution

Podacium replaces fragmented international platforms with a **single, integrated, sovereign ecosystem** built specifically for the Algerian market. A student completes a Data Science course on Podacium Learn → earns a verifiable Skill Passport → lands a freelancing project using that credential → tracks their growing revenue in Podacium BI.

**One platform. One wallet. Infinite growth.**

## The Three Pillars

An integrated ecosystem powering Algeria's digital economy

### 🎓 EdTech
Public Launch — Sep 23, 2026

Structured Learning Paths with ordered modules, HLS adaptive-bitrate video (720p/1080p via AWS MediaConvert + CloudFront).

- Interactive Quizzes — MCQ, true/false, short answer with scoring & retry cooldown
- Verifiable Certificates — PDF with digital signature, QR code, public verification URL
- Skill Passport — Portable, verified credential recognized across the ecosystem
- Instructor Dashboard — Enrollment analytics, content moderation workflow
- Collaborative Filtering — ML-driven course recommendations
- Full-Text Search — PostgreSQL tsvector-powered course discovery

### 💼 Freelancing
Closed Beta — Oct 1, 2026

A DZD-native project marketplace where Algerian freelancers connect with clients, protected by smart contracts and escrow.

- Project Listings — Budget, timeline, skill requirements, milestone-based
- Proposal Engine — Bid with credentials from your Skill Passport
- Smart Contracts — Milestone-based delivery with automated escrow release
- DZD Wallet — Deposit, payout, full transaction history (Chargily Pay)
- Freelancer Tiers — New → Standard → Pro → Enterprise (0% commission first 3 projects)
- Dispute Resolution — Mediation, evidence submission, appeal process

### 📊 Business Intelligence
Pilot — Jan 1, 2027

AI-driven analytics for Algerian SMEs — replacing Power BI and Tableau with a local-first solution.

- Dataset Upload — CSV, JSON, XLSX up to 100MB via DuckDB engine
- AI Dashboard Builder — 18+ widget types (charts, KPIs, tables, maps)
- ML Model Training — Automated pipeline with versioning & quality monitoring
- Automated Reports — PDF/email scheduling via ReportLab
- Algerian Health Score — Proprietary SME health metric
- Localized Analytics — Ramadan seasonality, Carnet/Kridi informal credit encoding

### 🧠 The Cross-Pillar Flywheel

Learn → Earn a verifiable certificate → Work → Win projects using that credential → Analyze → Track revenue & grow → Repeat
