## 🚀 Overview

Podacium is a sovereign, three-pillar SaaS platform purpose-built for the **Algerian market**, unifying **Education**, **Freelancing**, and **Business Intelligence** into a single ecosystem. We eliminate the structural barriers between talent and economic opportunity.

| Pillar | Launch | What it does |
|--------|--------|-------------|
| **🎓 EdTech** | Jul 15, 2026 (Public) | Structured courses, video lessons, quizzes, verifiable certificates & Skill Passport |
| **💼 Freelancing** | Oct 1, 2026 (Beta) | Project marketplace, escrow payments, smart contracts, milestone delivery |
| **📊 BI** | Jan 1, 2027 (Pilot) | Dataset upload, AI dashboards, ML model training, automated reports |

### 🧠 Cross-Pillar Flywheel

A student completes a course → earns a verifiable certificate → uses it as their calling card on the freelancing marketplace → revenue flows into their BI dashboard. **One platform, infinite growth.**

---

## 🌍 Why Podacium?

Algeria's digital economy lacks an integrated platform connecting learning to earning to analyzing. Podacium fills this gap with:

- **DZD-native payments** via Chargily Pay (EDAHABIA / CIB)
- **Decree 1275 compliant**
- **Darja & Tamazight content**
- **Local labor market categories** — AI-resistant, human-certified
- **Informal credit encoding** (Carnet / Kridi)
- **4 languages**: English, Français, العربية, دارجة

## 🏗️ Tech Stack

| Layer | Technology |
|-------|-----------|
| **Frontend** | Next.js 15, React 18, TypeScript, Tailwind CSS 4 |
| **Backend** | FastAPI (Python 3.11), Prisma ORM, Celery, Redis 7 |
| **Database** | PostgreSQL 16 (94 models) |

| **Video** | AWS MediaConvert + CloudFront (HLS) |

| **Monitoring** | Sentry, Prometheus, Grafana |
